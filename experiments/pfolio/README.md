# P-FOLIO

Syllogism classification experiments based on P-FOLIO, enriched with logical notations.

## Description
Syllogism classification experiments based on FOLIO.

The dataset was extended with CLGC and experiments performed according to [[1]](#ref-1).

The extended dataset can be found on Hugging Face [[2]](#ref-2).
